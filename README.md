# Introduction to Data Science for Engineers

**Course Code:** CS3006

## 1. Early Heart Stroke Prediction

A data science project focused on analyzing health-related data to identify patterns and predict the risk of stroke using machine learning techniques. The project involves data preprocessing, handling missing values, exploratory data analysis, model development, and prediction.

## 2. ScrubVerse – Data Rescue Game 🎮

An interactive educational game designed to make learning data-cleaning concepts engaging. Players complete challenges involving identifying and handling data quality issues, understanding missing values, and applying data preprocessing techniques through gameplay.

**Technologies Used:** HTML, CSS, JavaScript.
